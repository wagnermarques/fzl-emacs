* 📚 O que é este sistema?

Este sistema substitui ferramentas externas como o *Zotero* ou *Mendeley*, trazendo toda a gestão de referências acadêmicas, artigos em PDF e anotações para dentro do Emacs. Inspirado pela filosofia Zettelkasten e pela palestra "Emacs as a fully-fledged reference manager" de Vidianos Giannitsis, este formato abandona pastas complexas em favor de bancos locais de texto plano fáceis de buscar.

Ele é movido a componentes principais integrados:
1. **Helm-BibTeX**: O motor de busca instantâneo para suas referências.
2. **Ebib**: Um gerenciador visual do banco de dados BibTeX.
3. **Biblio.el**: Para buscar metadados de artigos online (DOI, ArXiv, Crossref) e importar magicamente.
4. **Ebib-Reading-List**: Para rastrear o que você precisa ler através de um arquivo org.
5. **Org-ref**: Para citar referências nativamente em documentos Org-mode.

* ⚙️ Onde ficam meus arquivos?

Seu Emacs está configurado para ler o diretório definido pela variável =FZLEMACS_BIBNOTES_HOME=.
Por padrão, este diretório é:
=/home/wgn/mnt/ext4/Researching-bibtex-manager-data=

Lá dentro, o sistema trabalha com a seguinte estrutura:
- =references.bib=: O arquivo principal que contém todas as suas referências (o banco de dados).
- =pdfs/=: A pasta onde você guarda os PDFs. Ao baixar ou mover PDFs para cá, certifique-se de que o nome seja exatamente a "Citation Key" (Chave BibTeX) do artigo. Ex: =smith2023.pdf=.
- =notes/=: Pasta onde o Emacs salvará automaticamente suas notas acadêmicas atreladas a cada referência.
- =reading-list.org=: Arquivo gerado pelo ebib para você acompanhar sua fila de leitura.

*(Lembre-se: Você pode mudar esse diretório ativo a qualquer momento usando o atalho =C-c d r=)*

* 🚀 Atalhos Principais (Desktoping Menu)

Todos os atalhos estão mapeados no prefixo *Desktoping* (=C-c d=) e também no menu superior =Desktoping -> Bibliography (BibTeX)=.

| Ação                                | Atalho Emacs | Descrição                                                                 |
|-------------------------------------+--------------+---------------------------------------------------------------------------|
| **Pesquisar Referências**           | =C-c d R=    | Abre o =helm-bibtex=. Busca interativa por autor, título ou ano.          |
| **Abrir Gerenciador Visual**        | =C-c d E=    | Abre o =ebib= para gerenciar a base e sua lista de leitura.               |
| **Busca Online (DOI/ArXiv)**        | =C-c d f=    | Abre o =biblio-lookup= para importar metadados da internet para o Ebib.   |
| **Mudar Diretório (FZLEMACS...)**   | =C-c d r=    | Alterna dinamicamente a pasta de bibliografia ativa sem reiniciar o Emacs.|

* 📥 Importando Referências da Internet (=C-c d f=)

Em vez de digitar os campos BibTeX na mão, deixe a internet fazer o trabalho (conforme demonstrado no vídeo do EmacsConf):
1. Pressione =C-c d f= (~biblio-lookup~).
2. O Emacs perguntará o que buscar. Você pode colar um *DOI*, ou digitar palavras-chave de um artigo (ex: "machine learning 2024").
3. Uma lista de resultados aparecerá. Navegue com as setas.
4. Pressione =Enter= em cima do resultado correto para exibir os detalhes.
5. Em seguida, pressione =c= para copiar o BibTeX, ou =i= para importar *diretamente* para o seu banco do =ebib=!

* 🗃️ Gerenciando o Banco e Lista de Leitura (=C-c d E=)

A interface do =Ebib= é seu "painel de controle" Zotero-like.
- **a**: Adiciona nova referência manualmente.
- **e**: Edita o campo do artigo selecionado.
- **d**: Deleta a referência.
- **s**: Salva o arquivo de banco de dados (=references.bib=).

**📚 Lista de Leitura (Ebib Reading List)**:
Para implementar o fluxo do EmacsConf de acompanhar o que precisa ser lido:
- Dentro do =Ebib=, ao selecionar um artigo, o pacote *ebib-reading-list* permite adicioná-lo à fila. (Procure pelos comandos =M-x ebib-reading-list...= para gerenciar itens de leitura em formato Org-mode).

* 🔍 Lendo, Anotando e Citando (=C-c d R=)

O =helm-bibtex= (=C-c d R=) é para o fluxo rápido do dia a dia enquanto você escreve.
1. Pressione =C-c d R=, digite parte do nome do autor.
2. Pressione =TAB= sobre a referência.
3. Ações disponíveis no painel:
   - =Open PDF, URL or DOI=: Se o arquivo =smith2023.pdf= estiver na pasta =pdfs/=, ele abre o arquivo!
   - =Edit notes=: Abre sua pasta =notes/= criando um arquivo focado nas suas anotações atrelado ao autor. (Uma abordagem *Zettelkasten* excelente para sua pesquisa).
   - =Insert citation=: Se estiver num buffer Org-mode, gera um link =cite:smith2023= para a bibliografia automática!
