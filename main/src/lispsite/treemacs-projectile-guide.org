* Introduction: The Power Duo (Projectile + Treemacs)

In modern software development, working across multiple repositories, microservices, and large directory hierarchies is standard. In Emacs, combining **Projectile** with **Treemacs** provides the ultimate balance between:

1. **Lightning-fast keyboard navigation** (Projectile + Helm)
2. **Rich visual project context** (Treemacs sidebar with Git status & icons)

#+BEGIN_QUOTE
*Core Philosophy:* Use Projectile to jump directly where you want to go in milliseconds without touching the mouse; use Treemacs to keep visual context of your directory structure and Git status.
#+END_QUOTE

** 1. Projectile Root Detection
Projectile automatically discovers the root of any project by looking for marker files:
- Version Control: ~.git~, ~.svn~, ~.hg~
- Build Systems: ~package.json~, ~pom.xml~, ~Cargo.toml~, ~composer.json~, ~Makefile~, ~CMakeLists.txt~
- Custom overrides: ~.projectile~

Once a root is identified, Projectile indexes the files (using fast alien indexing like ~git ls-files~ or ~fd~) to allow instant searching across thousands of files.

** 2. Treemacs Multi-Project Workspaces
Unlike traditional single-directory file trees, Treemacs operates on *Workspaces*. A single workspace can hold multiple independent project roots (e.g., your backend API, frontend SPA, and DevOps repo all visible side-by-side).

** 3. The `treemacs-projectile` Bridge
The ~treemacs-projectile~ package integrates both systems:
- When you are in a Projectile project, one command adds and focuses that project in Treemacs (~C-c p h~ or ~C-c p T~).
- *Follow Mode* (~treemacs-follow-mode~): As you switch files or jump via Projectile/Helm, Treemacs automatically expands the folder and highlights the active file in the sidebar.

** 4. Git Status & Magit Integration
- Treemacs shows real-time Git indicators (modified files in orange/yellow, untracked in green, conflicts in red).
- Jump directly from any project file into **Magit** (~C-x g~) for staging and committing.

* Step-by-Step Productivity Workflows

** Workflow 1: Switching Projects at the Speed of Thought
When moving from one task to another:
1. Press =C-c p p= (~projectile-switch-project~).
2. Type 2-3 letters of the project name with Helm fuzzy search and hit =RET=.
3. Press =C-c t= or =C-c p T= to ensure Treemacs displays the new project root in the sidebar.

** Workflow 2: Instant File Finding (No Tree Clicking Needed)
Instead of manually unfolding 6 levels of folders in a tree:
1. Press =C-c p f= (~projectile-find-file~ with Helm).
2. Type partial fuzzy words, e.g., ~auth serv ts~ for ~src/services/auth.service.ts~.
3. Hit =RET=.
4. Notice that Treemacs automatically scrolls and highlights the opened file in the sidebar, providing instant visual context of sibling files!

** Workflow 3: Multi-Repository Workspaces
If you are developing a full-stack feature:
1. Open a file in the frontend repo -> run =M-x treemacs-add-and-display-current-project=.
2. Open a file in the backend repo -> run =M-x treemacs-add-and-display-current-project=.
3. Both projects are now pinned in your Treemacs sidebar. You can drag and drop, compare structure, or switch between them effortlessly.

** Workflow 4: Project-Wide Search & Refactoring
1. Search project-wide: =C-c p s g= (~projectile-grep~) or =helm-projectile-grep~ / =helm-projectile-rg=.
2. Replace project-wide: =C-c p r= (~projectile-replace~) to rename functions or variables across the entire repository.
3. Invalidate/Refresh cache: =C-c p i= if newly created external files haven't appeared in Projectile yet.

* Configuration Architecture in `fzl-emacs`

The configuration is modularly split inside ~main/src/lispsite/~:

1. **`pkgconfig-projectile.el`**:
   - Enables ~projectile-mode~ globally.
   - Binds prefix keymap to =C-c p=.
   - Integrates with *Helm* (~helm-projectile~).
   - Configures caching and ignores noisy directories (~node_modules~, ~target~, ~dist~, ~.venv~).

2. **`pkgconfig-treemacs.el`**:
   - Configures UI (35 columns width, icons, fringe indicators).
   - Enables ~treemacs-follow-mode~ (synchronizes tree with editor file).
   - Loads ~treemacs-projectile~ with bindings on =C-c p h= and =C-c p T=.
   - Loads ~treemacs-magit~ and ~treemacs-all-the-icons~.

3. **`init.el`**:
   - Loads ~pkgconfig-projectile~ followed by ~pkgconfig-treemacs~ and ~pkgconfig-helm~.

* Pro-Tips for Maximum Productivity

1. **Ignore build output using `.projectile`:**
   Add a ~.projectile~ file in your project root to ignore heavy folders:
   #+BEGIN_SRC text
   -/build
   -/dist
   -/target
   -/node_modules
   -/.cache
   #+END_SRC

2. **Keep Treemacs on the left and focus on code:**
   Use =M-0= to quickly jump into Treemacs to browse, make directory operations, and press =q= or =RET= to return to editing immediately.

3. **Clean workspace hygiene:**
   When finished with a feature across multiple files, use =C-c p k= (~projectile-kill-buffers~) to close all project-related buffers at once and keep Emacs clean and snappy.

4. **Combine with Magit:**
   Use =C-x g= while editing any file to open Magit. Any staged/committed changes will update Treemacs status badges in real-time.
