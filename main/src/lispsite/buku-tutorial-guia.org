* 📌 Introdução: O que é o Buku e Por Que Utilizá-lo?

O *Buku* é um gerenciador de favoritos de linha de comando (CLI) extremamente rápido, seguro e focado em privacidade.

** Principais Vantagens:
- **100% Local e Offline:** Os seus favoritos ficam salvos exclusivamente no seu computador em um banco SQLite (`bookmarks.db`).
- **Independente de Navegador:** Permite usar múltiplos navegadores (Firefox, Chrome, Brave, Edge, Nyxt, etc.) sem ficar preso à sincronização proprietária de nenhum deles.
- **Integração Total com Emacs:** Permite buscar, filtrar e abrir URLs instantaneamente sem sair do seu editor favorito.
- **Metadados Automáticos:** Busca título de páginas da web automaticamente ao salvar links.
- **Sistema Poderoso de Tags e Busca:** Suporta filtros booleanos (AND, OR, NOT) e tags ilimitadas.
- **Importação/Exportação Universal:** Lê e gera o formato padrão Netscape HTML (compatível com todos os navegadores do mercado) e Markdown.

* 🗄️ Onde Ficam Salvos os Favoritos? (Configuração do Banco)

Por padrão, o Buku salva o banco SQLite em:
#+BEGIN_EXAMPLE
~/.local/share/buku/bookmarks.db
#+END_EXAMPLE

** Banco de Dados Versionado no Projeto `fzl-emacs`:
No `fzl-emacs`, o banco de dados é mantido e versionado diretamente dentro do projeto em:
#+BEGIN_EXAMPLE
<raiz-do-fzl-emacs>/bookmarks/bookmarks.db
#+END_EXAMPLE
Dessa forma, todos os seus favoritos ficam salvos no repositório git e são preservados em qualquer máquina ao clonar o projeto!

Caso queira usar o CLI do Buku no seu terminal acessando esse mesmo banco:
#+BEGIN_SRC bash
export BUKU_DB_PATH="$HOME/mnt/ext4/Projects-Srcs/Projects-Srcs-Desktop/fzl-emacs/bookmarks/bookmarks.db"
# Ou passar o parâmetro --db diretamente:
buku --db "$HOME/mnt/ext4/Projects-Srcs/Projects-Srcs-Desktop/fzl-emacs/bookmarks/bookmarks.db" -p
#+END_SRC

* 🔍 Regra de Unicidade de URLs e Múltiplos Grupos no Buku

No Buku, **as URLs são estritamente únicas por banco de dados** (restrição =UNIQUE= no SQLite).
Se você tentar adicionar uma URL que já existe, o Buku rejeitará a duplicata:
#+BEGIN_EXAMPLE
[ERROR] URL [https://meusite.com] already exists at index 3
#+END_EXAMPLE

** Como o Buku organiza múltiplos grupos?
No modelo do Buku, **grupos são modelados através de tags**.
Um mesmo favorito pode ter quantas tags (grupos) você desejar (ex: =#projetos, dev, mobile, estudos=).
Portanto, para que um link pertença a outro grupo, você *não duplica o registro*: basta **anexar a nova tag** ao favorito existente!

*** 1. Pelo terminal (CLI):
#+BEGIN_SRC bash
# Adiciona a tag 'estudos' ao favorito de índice 3 sem apagar as tags que ele já tem:
# (Atenção: deve haver um espaço entre o '+' e o nome da tag)
buku -u 3 --tag + estudos

# Também é possível atualizar buscando pela URL:
buku -u --tag + estudos -s "https://meusite.com"
#+END_SRC

*** 2. Pelo Emacs (fzl-emacs):
- *Detecção Automática:* Ao usar =C-c d b a= (~desktoping-buku-add-bookmark~), se a URL informada já existir no banco, o Emacs detecta o índice existente e **anexa automaticamente o novo grupo/tag ao favorito**, avisando você no rodapé.
- *Edição Manual de Tags:* Pressione =C-c d b T= (~desktoping-buku-edit-tags~), selecione o favorito pelo autocompletar e altere ou adicione as tags diretamente.

*** 3. E se você quiser bases totalmente separadas?
Caso queira isolamento completo de coleções (ex: trabalho vs. pessoal), use arquivos de banco de dados diferentes via parâmetro =--db=:
#+BEGIN_SRC bash
buku --db pessoal -a https://meusite.com
buku --db trabalho -a https://meusite.com
#+END_SRC

* 💻 Guia da Linha de Comando (CLI)

** 1. Adicionar Favoritos
#+BEGIN_SRC bash
# Adicionar URL básica (busca título automaticamente na web):
buku -a https://orgmode.org

# Adicionar com tags separadas por vírgula e comentário:
buku -a https://github.com/jarun/buku cli,tools,bookmarks -c "Repositório oficial do Buku"

# Adicionar sem buscar metadados na web (offline):
buku -a https://meusite.local --offline dev,local
#+END_SRC

** ⚡ Equivalente no Emacs:
- *Atalho Global:* =C-c d b a= (~desktoping-buku-add-bookmark~)
- *Pelo Menu:* =Desktoping -> Bookmarks (Buku) -> Add New Bookmark=
- *No buffer do ebuku:* Pressione =a= para adicionar.
- *💡 Dica de Produtividade no Emacs:* Se o cursor estiver sobre uma URL ou se você acabou de copiar um link (clipboard), o Emacs preenche a URL automaticamente no prompt! No prompt de *Tags / Group*, o Emacs oferece autocompletar com todos os seus grupos existentes (ou você pode digitar novos nomes separados por vírgula, ex: =projetos, dev, backend=).

** 2. Pesquisar Favoritos
#+BEGIN_SRC bash
# Busca genérica (busca no título, URL, comentário e tags):
buku -s emacs

# Busca restrita apenas por tags:
buku --st emacs,orgmode

# Busca por tags com lógica booleana:
# Tags 'dev' E 'linux', mas SEM 'python':
buku --st dev + linux - python
#+END_SRC

*** ⚡ Equivalente no Emacs:
- *Atalho Global:* =C-c d b s= (~desktoping-buku-search-and-open~)
- *Pelo Menu:* =Desktoping -> Bookmarks (Buku) -> Search & Open Bookmark=
- *Como Funciona:* Abre o minicommando interativo do Emacs com busca fuzzy instantânea por título, URL ou tags (🏷️), permitindo filtrar em tempo real e teclar =RET= para abrir diretamente no navegador padrão.

** 3. Abrir Favoritos no Navegador
#+BEGIN_SRC bash
# Abre o favorito de número #12 no navegador padrão:
buku -w 12

# Abre o primeiro resultado de uma busca diretamente:
buku -s github -w 1
#+END_SRC

*** ⚡ Equivalente no Emacs:
- Ao usar =C-c d b s=, basta selecionar qualquer favorito da lista e teclar =RET= para abrir automaticamente no navegador padrão do desktop.
- No buffer do *ebuku* (=C-c d b b=), posicione o cursor sobre o favorito e tecle =RET=.

** 4. Listar e Navegar
#+BEGIN_SRC bash
# Listar todos os favoritos paginados:
buku -p

# Listar os últimos 10 favoritos adicionados:
buku -p -n 10
#+END_SRC

*** ⚡ Equivalente no Emacs:
- *Atalho:* =C-c d b b= (~desktoping-buku-open-manager~) para abrir o gerenciador interativo do `ebuku`, listando todos os favoritos com suporte a navegação por teclado.

** 5. Editar e Atualizar Favoritos
#+BEGIN_SRC bash
# Menu interativo para editar título, URL, tags e comentários do favorito #5:
buku -u 5

# Adicionar tags extras ao favorito #5 sem apagar as existentes:
buku -u 5 --tag + nova_tag,tutorial

# Remover uma tag do favorito #5:
buku -u 5 --tag - tag_antiga
#+END_SRC

*** ⚡ Equivalente no Emacs:
- *Atalho Global:* =C-c d b T= (~desktoping-buku-edit-tags~)
  - Selecione o favorito pelo autocompletar e edite as tags diretamente.
- Caso o pacote opcional =ebuku= esteja instalado (=M-x package-install RET ebuku=), você também pode usar =C-c d b b= e teclar =t= sobre a linha.

** 6. Deletar Favoritos ou Grupos
#+BEGIN_SRC bash
# Deleta o favorito número #5:
buku -d 5

# Remover uma tag/grupo de todos os favoritos (mantendo os links):
buku --replace nome_do_grupo

# Deletar todos os favoritos pertencentes a um grupo:
buku -t nome_do_grupo -d
#+END_SRC

*** ⚡ Equivalente no Emacs:
- *Deletar Favorito:* =C-c d b d= (~desktoping-buku-delete-bookmark~)
  - Abre a seleção interativa para escolher o favorito e removê-lo após confirmação.
- *Deletar Grupo/Tag:* =C-c d b D= (~desktoping-buku-delete-tag~)
  - Permite escolher entre:
    1. Remover a tag de todos os links (mantendo os favoritos).
    2. Excluir permanentemente todos os favoritos pertencentes a esse grupo.
- No buffer do *ebuku* (se instalado via =C-c d b b=), tecle =d= sobre o favorito.

* 🔄 Portabilidade: Migração e Sincronização Entre Navegadores

** Passo 1: Exportar dos seus navegadores atuais
- No **Firefox**: Pressione =Ctrl+Shift+O= -> /Importar e Backup/ -> /Exportar favoritos como HTML.../
- No **Chrome / Brave / Edge**: Pressione =Ctrl+Shift+O= -> Menu de 3 pontinhos -> /Exportar favoritos/

** Passo 2: Importar para o Buku
#+BEGIN_SRC bash
buku -i ~/Downloads/bookmarks_firefox.html
#+END_SRC

** Passo 3: Exportar do Buku para atualizar outros navegadores
#+BEGIN_SRC bash
buku -e ~/Desktop/todos_os_favoritos.html
#+END_SRC
Agora, em qualquer navegador, basta ir em /Importar Favoritos de arquivo HTML/ e carregar o arquivo gerado!

O seu ambiente Emacs possui total integração com o Buku via menu e atalhos globais prefixados em =C-c d b=.
O navegador padrão configurado para abrir os links é o *Chromium Browser* (=/usr/bin/chromium-browser=).

** 📋 Como Visualizar os Favoritos e Abrir no Navegador pelo Emacs:

*** ⚡ Método 1: Busca Rápida e Abertura Direta (=C-c d b s=) [Recomendado no Dia a Dia]
1. No Emacs, pressione o atalho:
   #+BEGIN_EXAMPLE
   C-c d b s
   #+END_EXAMPLE
   /(ou clique no menu: *Desktoping -> Bookmarks (Buku) -> Search & Open Bookmark*)/

2. Uma lista interativa com busca fuzzy aparecerá no rodapé do Emacs com todos os seus favoritos formatados:

   [#2] leitor de biblia (https://wagnermarques.github.io/biblereaderapp/)  🏷️ projetos-pess
   [#3] GNU Operating System (https://gnu.org)  🏷️ emacs, gnu
   #+END_EXAMPLE

3. *Filtre em tempo real:* Digite qualquer termo (ex: =biblia=, =gnu=, =projetos= ou parte do link).
4. *Abra no navegador:* Pressione =RET= (Enter) sobre o favorito selecionado. O Emacs abrirá a página imediatamente no *Chromium Browser*.

*** 🗂️ Método 2: Visualizador e Gerenciador em Buffer Completo (=C-c d b b=)
1. No Emacs, pressione:
   #+BEGIN_EXAMPLE

   #+END_EXAMPLE
   /(ou =M-x ebuku=)/

2. Um buffer chamado =*ebuku*= será aberto exibindo todos os seus favoritos em formato tabular.
3. *Controles e Teclas de Navegação no buffer:*

   - =t=: Gerenciar e editar tags do favorito.

2. O Emacs mostrará uma lista com os seus **Grupos/Tags** e a quantidade de favoritos em cada um (ex: =🏷️ projetos (2 bookmarks)=, =🏷️ emacs (1 bookmark)=).
3. Selecione o grupo desejado para visualizar a lista com **todos os itens** pertencentes àquele grupo.
4. Pressione =RET= no favorito desejado para abrir imediatamente no Chromium.

* 🌐 Extensões de Navegador e Como Salvar Grupos de Abas Abertas

Sim! O Buku possui a extensão oficial **Bukubrow**, além de métodos nativos práticos para salvar todas as abas abertas de uma janela sob uma mesma tag/grupo e reabri-las quando quiser.

** 🔄 O Fluxo Completo de Trabalho:
#+BEGIN_EXAMPLE
 [ Abas Abertas no Navegador ]
              │
              ├── Opção 1: Extensão Bukubrow ("Save open tabs to staging area")
              ├── Opção 2: Nativo (Ctrl+Shift+D -> Exportar HTML -> C-c d b i)
              ├── Opção 3: Emacs Batch (Copiar URLs -> C-c d b B)
              └── Opção 4: Terminal (Script/Loop bash com arquivo de URLs)
              │
              ▼
 [ Banco SQLite do Buku: bookmarks/bookmarks.db ]
   (Armazenado localmente, seguro e versionado no Git com a Tag/Grupo)
              │
              ▼
 [ Reabrir Todas as Abas Quando Quiser ]
   No Emacs: C-c d b o (desktoping-buku-open-all-in-tag) -> Abre tudo no Chromium!
#+END_EXAMPLE

** Opção 1: Extensão Oficial Bukubrow (com Staging Area de Abas)
A **Bukubrow** é a extensão WebExtension oficial para Chrome, Chromium, Brave, Firefox e Edge.

*** O que ela faz:
- Conecta o navegador diretamente ao seu executável local do =buku= via *Native Messaging*.
- Possui uma **Área de Preparação (/Staging Area/)** que captura todas as abas abertas da janela atual com um clique.
- Permite revisar os títulos, excluir abas indesejadas antes de salvar e definir as tags do grupo.
- Atalho global no navegador (=Ctrl+Shift+B=) para busca instantânea conectada ao seu banco local.

*** Passo a Passo de Instalação no Linux:
1. *Instale a extensão no seu navegador:*
   - Para *Chrome*, *Chromium*, *Brave*, *Edge* e *Opera*: instale diretamente pela [[https://chromewebstore.google.com/detail/bukubrow/ghniladkapjacfajioheldbegfignflm][Chrome Web Store (Bukubrow)]].
     /(No Edge e no Opera, permita extensões da Chrome Web Store se solicitado)/.
   - *Nota sobre o Firefox:* A Mozilla removeu/deslistou a extensão da loja oficial (AMO). Para usar no Firefox, é necessário compilar o código fonte de [[https://github.com/samhh/bukubrow-webext][samhh/bukubrow-webext]] via =make webext= e carregar manualmente em =about:debugging=, ou utilizar os métodos nativos (Opção 2 abaixo) de exportação/importação HTML.
2. *Instale o conector nativo (host script) no Linux:*
   O navegador precisa de permissão para conversar com o binário do Buku.
   - *Via Ansible (Recomendado - automatizado em todos os navegadores):*
     #+BEGIN_SRC bash
     ansible-playbook -K playbooks/desktopmachine-install-browsers.yml
     #+END_SRC
   - *Ou manualmente via binário oficial do Bukubrow Host:*
     #+BEGIN_SRC bash
     sudo curl -sL -o /usr/local/bin/bukubrow https://github.com/samhh/bukubrow-host/releases/download/v5.4.0/bukubrow-linux-amd64
     sudo chmod +x /usr/local/bin/bukubrow
     bukubrow --install-chrome --install-chromium --install-brave --install-edge --install-firefox
     #+END_SRC
   /(O Bukubrow registra os manifestos de native messaging para Chrome, Chromium, Brave, Edge e Firefox)./
3. *Como Salvar o Grupo de Abas:*
   - No navegador, clique com o botão direito em qualquer área da página.
   - Selecione: *Bukubrow* -> *Save open tabs to staging area*.
   - Abra a janela da Bukubrow (ou tecle =Ctrl+Shift+B=).
   - Na aba de Staging, você verá todas as abas capturadas.
   - Digite o nome da **Tag/Grupo** desejada (ex: =projeto-x, pesquisa=) e confirme para salvar no banco!

---

** Opção 2: Método Nativo Sem Extensões (Atalho do Navegador + Importação no Emacs)
Ideal se você não quiser instalar extensões e deseja salvar um grupo de abas imediatamente:

1. *Salvar as abas em uma pasta de favoritos no navegador:*
   - Na janela com as abas abertas no Chromium/Chrome/Brave, tecle:
     #+BEGIN_EXAMPLE
     Ctrl + Shift + D
     #+END_EXAMPLE
     /(ou botão direito na barra de guias -> "Adicionar todas as guias aos favoritos...")/.
   - No campo "Nome da pasta", digite o **nome do seu grupo/tag** (ex: =pesquisa-ia=) e salve na "Barra de favoritos".
2. *Exportar os favoritos para HTML:*
   - Abra o gerenciador de favoritos do navegador: =Ctrl + Shift + O=.
   - Clique no menu de 3 pontinhos (=⋮=) no canto superior direito -> **Exportar favoritos**.
   - Salve o arquivo (ex: =~/Downloads/abas_salvas.html=).
3. *Importar diretamente no Emacs:*
   - No Emacs, tecle:
     #+BEGIN_EXAMPLE
     C-c d b i
     #+END_EXAMPLE
     /(ou menu: Desktoping -> Bookmarks (Buku) -> Import from HTML)/.
   - Selecione o arquivo =abas_salvas.html=.
   - O Buku importará todas as URLs e **criará automaticamente a tag com o nome da pasta** (=pesquisa-ia=)!
4. *(Opcional)* Você pode agora apagar a pasta criada no navegador para mantê-lo limpo, pois todos os links estão guardados de forma permanente no banco SQLite do Buku.

** Opção 3: Adição em Lote pelo Emacs com `desktoping-buku-add-batch` (=C-c d b B=)
Se você copiou links de abas (usando extensões leves como /Copy All URLs/, /TabCopy/, ou uma lista em texto):

1. No Emacs, pressione o atalho:
   #+BEGIN_EXAMPLE
   C-c d b B
   #+END_EXAMPLE
   /(ou menu: Desktoping -> Bookmarks (Buku) -> Add Batch Bookmarks (Paste URLs))/
2. Escolha ou digite a **Tag/Grupo** para associar a todos esses links (com autocompletar).
3. Cole as URLs (separadas por espaço ou quebra de linha) e tecle =RET=.
   /(Se você já copiou uma URL ou lista de links para a área de transferência, o Emacs já sugere o conteúdo do clipboard automaticamente no prompt!)/
4. O Emacs cadastra todas as URLs e aplica a tag informada. Se alguma URL já existia previamente no banco, o novo grupo é anexado a ela sem duplicar o registro!

** Opção 4: Adição em Lote via Linha de Comando (CLI / Terminal)
Se você salvou uma lista de URLs em um arquivo de texto simples (ex: =urls.txt=):

#+BEGIN_SRC bash
# Adiciona cada URL do arquivo associando ao grupo 'meu-projeto':
while read -r url; do
  buku --db "$HOME/mnt/ext4/Projects-Srcs/Projects-Srcs-Desktop/fzl-emacs/bookmarks/bookmarks.db" -a "$url" meu-projeto
done < urls.txt
#+END_SRC

** 🚀 Como Reabrir Todas as Abas do Grupo Quando Quiser (=C-c d b o=)
Depois de salvar suas abas em um grupo/tag, você pode fechar o navegador sem preocupação.
Quando quiser retomar o trabalho com todos aqueles links:

1. No Emacs, pressione:
   #+BEGIN_EXAMPLE
   C-c d b o
   #+END_EXAMPLE
   /(desktoping-buku-open-all-in-tag)/
2. Escolha o Grupo/Tag (ex: =pesquisa-ia=).
3. O Emacs pergunta: =Open all N bookmarks for group 'pesquisa-ia' in Chromium? (yes or no)=.
4. Digite =yes= e o Chromium abrirá **todas as abas do grupo simultaneamente**!

* 💾 Estratégia de Backup e Sincronização

Como o Buku usa apenas um arquivo (`bookmarks.db`), você pode:
1. Incluí-lo em um repositório Git privado.
2. Usar o atalho do menu **Desktoping -> Cloud & Synchronization -> Rclone** para sincronizar com seu Google Drive (`GDrive_wgn:`).
3. Fazer backup automático com um cron job simples:
